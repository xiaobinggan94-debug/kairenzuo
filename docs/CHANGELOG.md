# 变更记录

## v1.0.0

首个公开版本。功能已经稳定，作为可以长期使用的成品发布，不是预览版。

- **中英双向查询**：输入英文给中文意思，输入中文给一句地道英文；结果分块显示【中文意思】【生词】【你可以这样回】【注意】【语法】，中文输入时是【英文】【音标】【缩写版】【语法】
- **语法讲解**：讲清这句话为什么这么说——构成公式、换成别的说法差在哪、依据是原文哪个词；没考点就写「没有」，不硬凑术语
- **缩写版**：分轻度 / 中度 / 重度三档，按聊天场合挑用
- **流式输出**：回答边走边显示，首字秒出，不用等整段生成
- **离线查词**：断网、代理挂了也能把句里的英文单词查成中文意思（内置两万常用词），变形词自动还原
- **口语学习**：音标 + 中文近音，SAPI 朗读（可选发音人、语速、可急停），生词本自动去重、可导出 CSV、卡片式复习
- **历史与追问**：最近 20 条历史可翻可搜，`Ctrl + F` 接着问上一句
- **其他**：一键复制整段或选中句、语气可切换、快捷键可改、界面缩放适配、数据目录自动打扫
- **一键诊断包**：出问题时菜单里点一下生成 zip，环境信息一次看全，API Key 与密钥串一律打码
